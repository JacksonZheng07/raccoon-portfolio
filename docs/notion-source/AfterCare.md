# AfterCare

Repo: https://github.com/JacksonZheng07/AfterCare
# Project Overview
AfterCare is a post-operative recovery tracking platform. It includes a patient app, surgeon portal, and admin console. The README describes daily check-ins, pain and symptom logging, wound photo analysis simulation, medication tracking, mobility/PT tracking, messaging, triage sorting, analytics, alert thresholds, mock EHR status, audit logs, and a model registry.
The project simulates a healthcare workflow across patients, clinicians, and administrators.
